# SPE_Miniproject

A simple calculator REST API built with Spring Boot and Maven. The main focus of this project is the CI/CD pipeline around it: code is pushed to GitHub, Jenkins builds and tests it, packages it into a Docker image, pushes the image to Docker Hub and deploys it with Docker Compose.

This is my mini-project for CSE 816 Software Production Engineering.

## Status

Work in progress. Instructions for building, testing, running and calling the API will be added as the project progresses.
